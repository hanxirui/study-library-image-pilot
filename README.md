# Study Library Image Pilot

「为建设祖国努力学习」小程序图片加载试验。本批包含 178 张学习图和 5 张原创标题封面。24 个系列各有封面，每系列最多 10 张。

`pilot.json` 记录封面与试读的图片键。图像文件位于 `images/<key>.jpg`。标记 `coverOnly` 的系列当前只提供封面。

## Complete learning gallery

The complete reading gallery contains 4187 JPEGs. See [gallery-index.json](gallery-index.json) for chapter order, paths and checksums. The earlier pilot URLs remain available.
